Octopus Red Barn Vendor Checks

This is the information page of Octopus Red Barn Vendor Checks, a private program that Red Barn Wholesale uses with its own QuickBooks Online company.

Every Friday the program lists the purchase orders of Red Barn's cash-in-advance vendors from Red Barn's own Fishbowl inventory system. Red Barn's staff mark the orders to pay, and the program creates one check per marked order in Red Barn's QuickBooks Online. It does nothing else in QuickBooks.

There is no sign-up and nothing to download here. If you reached this page from QuickBooks, you can close it.

Octopus Red Barn Vendor Checks is a private integration built for Red Barn Wholesale, Shelby Township, Michigan. It is not offered to the public. Built and maintained for Red Barn Wholesale by Midwest AI Systems (midwestsystems.ai).
